# review-dashboard Specification

## Purpose

쇼핑 리뷰 AI 분석기의 메인 대시보드 셸을 정의한다. 서비스 정체성, 현재 데이터 모드, 분석 대상 상품, 샘플 데이터 인덱싱 제어, 최근 질문 히스토리를 사용자에게 제공한다.

## Requirements

### Requirement: 2단 대시보드 레이아웃
메인 페이지(`/`)는 좌측 사이드바와 우측 채팅 영역으로 구성된 2단 레이아웃을 SHALL 표시한다. 채팅 영역은 남은 너비 전체를 차지하고, 메시지 스트림만 세로 스크롤되며 입력창은 화면 하단에 고정되어야 한다(MUST).

#### Scenario: 데스크톱 화면 진입
- **WHEN** 사용자가 너비 1024px 이상의 화면에서 `/`에 접속하면
- **THEN** 좌측에 사이드바, 우측에 상품 배너·메시지 스트림·입력창이 있는 채팅 영역이 함께 보인다

#### Scenario: 모바일 화면 진입
- **WHEN** 사용자가 너비 768px 미만의 화면에서 `/`에 접속하면
- **THEN** 사이드바는 숨겨지고, 채팅 영역 상단의 메뉴 버튼으로 사이드바를 열고 닫을 수 있다

### Requirement: 서비스 타이틀과 데이터 모드 배지
사이드바 상단은 서비스 타이틀 "쇼핑 리뷰 AI 분석기"와 현재 데이터 모드 배지를 SHALL 표시한다. 서버 환경변수 `USE_MOCK`이 `'false'`이면 "실데이터 모드", 그 외(미설정 포함)에는 "Mock 모드"로 표시해야 한다(MUST). 두 배지는 색상과 아이콘으로 구분되어야 한다.

#### Scenario: USE_MOCK 미설정
- **WHEN** `USE_MOCK` 환경변수가 설정되지 않은 상태로 페이지를 렌더링하면
- **THEN** 배지에 "Mock 모드"가 표시된다

#### Scenario: USE_MOCK=false
- **WHEN** `USE_MOCK=false`로 페이지를 렌더링하면
- **THEN** 배지에 "실데이터 모드"가 표시된다

### Requirement: 샘플 데이터 인덱싱 버튼
사이드바는 [샘플 데이터 인덱싱] 버튼을 SHALL 제공한다. 클릭 시 인덱싱 API(`POST /api/ingest`)를 호출하고, 버튼은 대기(idle)·진행 중(loading)·완료(success)·실패(error) 상태를 시각적으로 구분해 표시해야 한다(MUST). 진행 중에는 재클릭이 불가능해야 한다.

#### Scenario: 인덱싱 진행 중
- **WHEN** 사용자가 버튼을 클릭해 요청이 진행 중이면
- **THEN** 버튼에 회전하는 스피너와 "인덱싱 중..." 문구가 표시되고 버튼은 비활성화된다

#### Scenario: 인덱싱 성공
- **WHEN** API가 `{ success: true, data: { count } }`를 반환하면
- **THEN** 완료 아이콘과 함께 "N건 인덱싱 완료" 형태로 처리 건수가 표시되고, 버튼은 다시 클릭 가능하다

#### Scenario: 인덱싱 실패
- **WHEN** API가 `success: false`를 반환하거나 네트워크 오류가 발생하면
- **THEN** 실패 아이콘과 오류 메시지가 표시되고, 버튼은 다시 클릭 가능하다

### Requirement: 최근 분석 질문 히스토리
사이드바는 현재 세션에서 사용자가 전송한 질문을 최신순 목록으로 SHALL 표시한다. 동일 질문은 중복 없이 맨 위로 이동하며, 최대 20개까지 유지한다. 항목 클릭 시 해당 질문 텍스트를 입력창에 채우고 포커스를 이동해야 한다(MUST). 자동 전송하지 않는다.

#### Scenario: 질문 전송 후 히스토리 반영
- **WHEN** 사용자가 "배터리 수명은 어때?"를 전송하면
- **THEN** 히스토리 목록 최상단에 "배터리 수명은 어때?"가 추가된다

#### Scenario: 히스토리 항목 재사용
- **WHEN** 사용자가 히스토리 항목을 클릭하면
- **THEN** 입력창에 해당 질문이 채워지고 포커스가 이동하며, 메시지는 전송되지 않는다

#### Scenario: 히스토리 없음
- **WHEN** 아직 전송한 질문이 없으면
- **THEN** "아직 분석한 질문이 없습니다" 안내 문구가 표시된다

### Requirement: 분석 대상 상품 배너
채팅 영역 상단은 분석 대상 상품 정보 배너를 SHALL 표시한다. 배너는 상품명(예: "노이즈캔슬링 무선 이어폰 PRO"), 카테고리, 리뷰 수, 평균 평점을 포함해야 한다(MUST).

#### Scenario: 배너 표시
- **WHEN** 사용자가 대시보드에 진입하면
- **THEN** 채팅 영역 상단에 상품명과 리뷰 수·평균 평점 요약이 표시된다
